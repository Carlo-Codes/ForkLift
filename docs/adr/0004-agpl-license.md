# AGPL-3.0 for the whole repository

ForkLift, including its built-in Exercise Library, is licensed AGPL-3.0. This keeps forks open
source. It also covers the future sync relay: anyone who runs a modified version of it as a hosted
service must share their changes, which plain GPL-3.0 doesn't require. MIT was rejected because it
allows closed-source forks. We write the Exercise Library ourselves rather than importing wger's
(CC-BY-SA), so there's no license mixing.
